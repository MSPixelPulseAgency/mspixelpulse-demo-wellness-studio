## V3 system

Midnight plum #201326, royal purple #60317D, orchid #A45BC7, luxury pink #E56AAB, soft blush #F5B5D2, champagne #D4AE73, warm ivory #FFF5F0, charcoal #17131C and icy-blue #8BC8FF. Primary controls use deeper pink/purple tonal variants for white-text contrast. Blue remains a subtle reflection/shadow.

Bodoni Moda display/italic at a readable medium weight, paired with local Manrope regular/semibold. Desktop navigation is approximately 15px. The header is detached from every viewport edge, with 28px radius (24px compact), layered plum glass, 28px backdrop blur, reflective highlights, blue/purple ambient depth and a gradient pill CTA. Mobile has a compact capsule and separate rounded disclosure panel. Native modal service choosers manage focus, trap focus, close on Escape and return focus to the trigger.

Shared radius tokens cover 26px cards, 16px fields, pill buttons and 24–28px dialogs. The new layout includes a portrait/inset hero, photographic category rail, mixed-size featured treatments, a controlled atmosphere film, beauty/wellness story tiles, a studio collage, rounded gallery and an illustrated local request journey. All interior pages receive a consistent redesign, while routes and original six service identifiers/prices/durations remain.

## Discovery and request behavior

36 services: six each in Massage, Facials, Body, Wellness, Packages and Beauty. Search matches service names, categories and descriptions; category, maximum-duration and shared-experience filters combine. Query filters are URL-backed and preserve input focus. Search reset, useful empty states and progressive loading are implemented. Cards link to every detail and preselected demo request.

The shared glass chooser has search, six category filters, clear selection, no-results reset, ArrowUp/ArrowDown/Home/End browsing, Enter selection, Escape close and native modal focus containment. Catalogue and picker use the same pure discovery function.

Booking: service → preferred date/time → sample contact details/acknowledgment → review, edit or copy. Date input is read from FormData at the transition to keep the review faithful to the rendered field; preferences persist when navigating back. Contact includes a service chooser, enquiry topics, local review, placeholder details, clearly fictional example hours, city-only location context and FAQs. No real spa address is invented.

Everything remains local browser state. No API, database, email, booking, payment or persistence is added. Test details are fictional and cleared. Physical facilities, real availability, credentials, reviews and outcomes are not represented.

## Media and performance

Six new licensed Pexels photographs (warm stones, manicure, cosmetic facial mask, singing bowl, foot massage, hair care) plus one licensed pool-film poster, with 28 local responsive WebP derivatives. The total library is 22 sources/88 derivatives. Credits are in docs/noire-media-sources.json. The 10-second adult pool film is locally encoded silent H.264, 540×960/24fps/fast-start, 753,357 bytes; credit and behavior are in docs/v3-video-sources.json.

Film sources attach only on explicit Play. They are muted/playsinline, have a static poster, loading/error feedback, manual pause and pause on viewport exit/document hiding. No simultaneous autoplay or unsolicited motion occurs, including with reduced motion. The still-image hero preserves first-load bandwidth; the film supports the atmosphere chapter and Experience page.

Primary media is preloaded responsively per route in index.html, after the viewport declaration. Maintain its small image map alongside src/data/studio.js when adding treatments. Below-fold images are lazy; gallery and catalogue progressively disclose more items. No runtime media/font hotlinks or new runtime dependencies.

## QA method

Existing Node contracts cover image provenance, local WebP assets, treatment IDs/prices and sitemap preservation. Added tests cover catalogue completeness, retained six service contracts, name/category/description search, combined filters, and the silent/fast-start licensed film.

Browser QA covers every route at 320/375/390/430/768/1024/1280/1440/1920, screenshots, heading/metadata/overflow checks, dropdown/search/filter/no-results/pagination behavior, mobile navigation, gallery keyboard controls, FAQ search, film playback/pause and the full demo request/edit/copy/clear flow. A 320px aromatherapy heading overflow and date-input commitment issue found in QA were fixed before release. Visually hidden headings are excluded from visual clipping measurements.

Initial local Lighthouse found late primary-image delivery (Home 89, Gallery 87). Responsive route-specific preload, removal of the portrait entrance animation and gallery image sizing/progressive loading improved the measured results. The subsequent local production-build audits were Home 91/100/100/100, Services 93/100/100/100, Booking 95/100/100/100 and Gallery 93/100/100/100. Production scores and final release IDs are recorded separately in release evidence. No score, field INP or physical-device result is fabricated.

This JavaScript/JSX project has no TypeScript compiler configuration. Lint, tests and production build are the appropriate code checks. Responsive browser emulation and automated accessibility audits do not establish physical-device proof, field Core Web Vitals or full WCAG conformance.
